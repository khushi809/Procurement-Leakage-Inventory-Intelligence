# Procurement Leakage & Inventory Intelligence

## Project Overview
An end-to-end data analytics project using Python, SQL, Excel, and Power BI to analyse business performance, logistics costs, delivery efficiency, and seller risk indicators.

## Tools & Technologies
- Python: Pandas, NumPy, Matplotlib, statistical analysis
- SQL: SQLite, joins, aggregations, CTEs, window functions
- Excel: KPI reporting, conditional formatting, dashboards
- Power BI: Interactive dashboards, KPI cards, slicers, visualisations

## Project Components
- Data inspection and quality checks
- Order and sales analysis
- Seller performance analysis using SQL
- Customer experience and delivery analysis
- Seller risk screening
- Excel business performance report
- Interactive Power BI dashboard

## Key Findings
- Approximately 99,441 orders
- Item sales value of approximately R$13.59 million
- Freight charges of approximately R$2.25 million
- Average delivery time of approximately 12.56 days
- 96 sellers flagged for high-priority review
- 623 sellers recommended for review

## Dataset
The project uses the Brazilian Olist e-commerce dataset. It supports seller, freight, delivery, and customer experience analysis. It does not directly establish procurement leakage or warehouse inventory loss.

## Business Value
The analysis helps identify freight-cost outliers, assess seller performance, understand delivery issues, and prioritise operational reviews.
